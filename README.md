# 🎵 Drake — Artist Page

> A fan-made interactive artist page dedicated to Drake and his music career.

An interactive web experience exploring Drake's discography, albums, mixtapes, and musical journey. The project combines a dark, minimal aesthetic with smooth interactions and an album-focused layout to create a modern artist portfolio.

---

## ✨ Features

* 🎧 **Interactive Discography** — Browse through Drake's albums and mixtapes.
* 💿 **Album Carousel** — Smooth, interactive album selection experience.
* ⭐ **Project Ratings** — Each project includes a personal rating.
* 📝 **Detailed Descriptions** — Learn more about the sound and significance of each project.
* 📅 **Release Information** — View release years and project types.
* 🎨 **Modern UI** — Dark, minimal design inspired by Drake's aesthetic.
* 📱 **Responsive Layout** — Designed to work across different screen sizes.
* ⚡ **Smooth Interactions** — Dynamic UI elements and transitions for a more immersive experience.

---

## 🛠️ Built With

* **HTML5** — Page structure and semantic markup
* **CSS3** — Layout, animations, styling, and responsive design
* **TypeScript** — Interactive functionality and application logic

---

## 🎨 Design

The website uses a dark, atmospheric visual style with subtle gold accents to create an aesthetic that fits the artist and the tone of his music.

The design focuses heavily on:

* Minimalism
* Album artwork
* Typography
* Spacing
* Smooth transitions
* Interactive elements

Rather than overwhelming the page with information, the goal is to make the discography itself the main visual focus.

## 🚀 Running Locally

Clone the repository:

```bash
git clone https://github.com/elemeTr0/Drake-Artist-Page.git
```

Navigate into the project:

```bash
cd Drake-Artist-Page
```

Then open the project in your preferred code editor and launch the website using a local development server such as **VS Code Live Server**.
